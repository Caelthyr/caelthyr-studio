# Caelthyr Studio

Live website: https://www.caelthyrstudio.com/

This repository contains only the public website, favicons, search metadata and font notices. GitHub Pages publishes main / (root). CNAME retains the custom domain. No backend, admin login, credentials or artwork images are included.

index.html is self-contained: layout, styles, scripts and fonts are embedded, so the same build works on desktop, tablet and phone. Content is defined in the load() function inside index.html.

CAE Studio font is derived from the supplied NOUS/Libre Bodoni font; see FONT-LICENSE.txt. CAE Mono is a modified IBM Plex Mono; see CAE-Mono-OFL.txt. Both use SIL OFL 1.1. Copyright and license notices are retained. Other font families use local operating-system fonts.

The implementation was authored for this site. No Signal-A source code, images, text passages, or proprietary font files are included. Visual inspiration is not a guarantee of legal clearance.
