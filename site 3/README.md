# Caelthyr Studio

A single-page static site using the supplied Caelthyr Studio artwork, with a small Instagram link fixed to the lower-right corner.

## Publish with GitHub Pages

1. Copy the contents of this folder to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the publishing branch (usually `main`) and `/ (root)`.
5. Add the custom domain in **Settings → Pages → Custom domain**.

After the exact domain is known, add a file named `CNAME` containing only that domain.
